# Glosario

> **Estado:** Aplicable.

| Término | Significado |
|---|---|
| **PC** | El equipo donde corre NB Sound y que sirve el catálogo |
| **Emparejar** | Vincular el teléfono a un PC escaneando su QR o escribiendo su código |
| **Manifiesto** | Lista de cambios del catálogo desde una versión de sincronización |
| **Lápida** | Aviso de borrado de una entidad en el manifiesto |
| **Selección** | Parte del catálogo que el PC envía a este teléfono |
| **Connect** | Controlar el reproductor del PC desde el teléfono y pasar la música de uno a otro |
| **Traspaso** | Mover la sesión (cola, pista, posición, modos) entre teléfono y PC |
| **Instrumental / karaoke** | Versión sin voz de una pista, generada por el PC |
| **Música local** | Audio guardado en el propio teléfono (Android) |
| **Huella** | SHA-256 del certificado del PC, fijada al emparejar |
| **Edición de demostración** | Compilación con `NB_SEED=true`, con catálogo y medios ficticios generados en el dispositivo |
