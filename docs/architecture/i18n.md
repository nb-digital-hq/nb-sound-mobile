# Internacionalización

> **Estado:** Implementado. Decisión: [ADR-006](../adr/006-internationalization.md).

| Pieza | Dónde |
|---|---|
| Función `tr` e idiomas | `lib/core/i18n/i18n.dart` |
| Catálogos | `lib/core/i18n/en.dart`, `lib/core/i18n/pt.dart` |
| Preferencia | `lib/core/i18n/idioma_controller.dart` (clave `idioma`) |
| Textos de Android | `android/app/src/main/res/values{,-en,-pt}/strings.xml` |
| Guardián | `tool/guardianes/i18n.dart` |

## Cómo se añade un texto

1. Se escribe en español dentro de `tr('...')`, con marcadores `{nombre}` para los valores:
   `tr('Faltan {n} pistas', {'n': n})`.
2. Se añade la misma clave en `en.dart` y `pt.dart`.
3. `dart run tool/guardianes/i18n.dart` confirma que no falta ni sobra nada.

`tr` se llama al construir, nunca en constantes: así un cambio de idioma se ve en la siguiente reconstrucción.

## Lo que no se traduce

Títulos, artistas, álbumes y nombres de playlists: son contenido de la persona y llegan del PC tal cual.
